# User Manual

## Getting Started
1. Log in with your credentials.
2. The Dashboard displays an overview of commodities and market trends.

## Features
- **Commodity/Market Management**: View available commodities and markets.
- **Price Entry**: Add new price records for commodities in specific markets.
- **Forecasting**: Select a commodity, market, and date to get a price prediction.
- **Reporting**: Export historical price data via the reports section.
